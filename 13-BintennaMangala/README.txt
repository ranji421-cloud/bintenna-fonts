• Pointed-pen calligraphy ශෛලිය: උඩට යන ඉරි කෙස් ගසක් තරම් සිහින්, පහළට අඳින ඉරි ඝන; 18° ඇල. බිංතැන්න පවුලේ දහතුන්වන අකුරයි.
• අකුරු හැඩතල: Noto Serif Sinhala (OFL 1.1) සිහින්ම ඇටසැකිල්ල, අලුතින් පෑනෙන් ලියූ ලෙස.

ස්වයංක්‍රීය වචන වලිග (OpenType Stylistic Set 1 / ss01):
  on කළ විට, හැම වචනයකම මුලට සහ අගට ලස්සන වලිග ඉබේම එකතු වේ. (වචනයට පෙර සහ පසු space එකක් තබන්න.)
  • Word: Font → Advanced → Stylistic sets → 1
  • Photoshop / Illustrator / InDesign: OpenType panel → Stylistic Set 1
  • Canva / Figma: Figma → Type details → Stylistic sets. Canva හි නොමැති නම් පහත වලිග අකුරු copy-paste කරන්න.
  • Web: font-feature-settings:"ss01" 1;

  U+E023 හදවත         U+E024 මංගල මුදු දෙක   U+E025 බෙදුම් ඉර
